# Skills

One file per capability. Every file follows
[`TEMPLATE.md`](TEMPLATE.md) and carries an honest status:

- `Discovered` — a source exists; nothing has been done with it yet.
- `Studying` — the source is being read; no practice yet.
- `Practiced` — worked through locally, with runnable code or notes.
- `Tested` — evaluated against a benchmark or test set, results recorded.
- `Integrated` — tested, and now part of the standard analysis workflow.

A skill is never promoted on the basis of reading alone.
