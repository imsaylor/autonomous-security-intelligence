# Skill Template

Copy this file for every new skill. Delete nothing; write "None yet"
where there is no evidence. A skill file with invented results is
worse than no skill file.

## How to use it

## Example implementation

Working code, a command sequence, or a link to the lab repository
where it lives. Must be runnable or inspectable.

## Test cases

The cases used to check the skill, and where they live.

## Test results

Recorded outcomes: what passed, what failed, dates, tool versions.
No results means the skill is not `Tested`.

## Limitations

What the skill cannot do, where it produces false positives, and what
would be needed to go further.
